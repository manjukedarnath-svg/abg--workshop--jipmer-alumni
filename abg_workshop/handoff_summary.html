ABG Interpretation Workshop — Design Handoff

13-case blood-gas teaching tool · single-file HTML app + 4 PDFs · live at stellar-griffin-9c37be.netlify.app

1 · Three views, one file

Participant

Route: /
Name + group → 13 cases. Fill interpretation, SID, case Qs. Autosave. Locked until moderator reads code.

Faculty

Route: /?faculty=1
Gold banner + two tabs (Cases & Answers · Cheat Sheet). No codes. Each case expands to full walkthrough.

Moderator

Route: /?mod=1
Three tabs. Codes & QR tab shows big 4-char code + join QR. Plus Cases & Answers and Cheat Sheet.

2 · Live session flow

1All 13 cases distributed (8 min settling) → 2Small group: 3 interpret · 3 discuss · 2 synthesise → 3Plenary: moderator reveals code → 4Participants unlock answers on phone → 5Expert comment · take-home · next case

13 cases × 15 min ≈ 3.25 hrs · or select 8 for 2 hrs.

6 · What works today

✓ Working

  • All 13 cases in all 3 views
  • Deterministic 4-char unlock codes (FNV-1a)
  • LocalStorage autosave, per group
  • Mobile-first single-column layout, bottom-sheet nav
  • Faculty view hides codes tab
  • QR auto-generation from moderator URL
  • 4 PDFs generated from same data

Gaps · improvement ideas

  • No cross-device sync (each phone isolated)
  • No live analytics for moderator
  • QR relies on external service (offline breaks)
  • No per-case timer visible
  • No “reset my answers” in participant view
  • No exit-ticket summary screen
  • Case data embedded — hard for non-devs to edit
  • ARIA / keyboard nav on mobile nav is minimal

7 · Questions for the designer

Product: should participants see a peer-comparison view (how did my group answer vs others) after unlock?
Visual: how to unify the print PDFs with the web app so they feel like one product?
Flow: should the moderator be able to broadcast the case switch to all participants?
Content: what's the clearest way to show a “persistently low HCO₃⁻ = the acid has changed character” teaching moment?
Motion: does the unlock reveal want a specific animation (rather than instant)?
Accessibility: WCAG AA pass — focus rings, contrast on gold-soft, screen reader labels.
